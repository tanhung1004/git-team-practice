# Git Team Practice

A tiny HTML/CSS/JavaScript project used to practice Git teamwork.

## Files

- `index.html` - page structure
- `style.css` - page styling
- `app.js` - small interaction
- `README.md` - project notes

## Git workflow we will practice

- `main`
- `develop`
- `feature/*`
- `hotfix/*`
- commit / push / pull
- merge
- merge conflict
